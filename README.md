# 동물 광클 레이스 — 실시간 멀티플레이

최대 10명이 하나의 공용 대기실에 접속하는 모바일 웹게임입니다. 최소 2명이 준비 완료하면 준비한 사람 중 누구나 경기 시작 버튼을 눌러 3초 후 출발합니다. 준비하지 않은 사람은 이번 경기에서 제외됩니다. 100회 탭으로 완주하고 최대 90초 후 결과/시상식이 표시됩니다.

## 로컬 실행 (PC)
1. Node.js 18 이상 설치
2. 폴더에서 터미널 열고 `npm install` 실행
3. `npm start` 실행
4. 브라우저에서 `http://localhost:3000` 접속

## 단톡방 링크 공유 (Render 예시)
1. 이 프로젝트 폴더를 GitHub 저장소에 업로드합니다 (ZIP은 먼저 압축 해제).
2. render.com 가입 후 **New > Web Service**에서 GitHub 저장소를 연결합니다.
3. Runtime: Node, Build Command: `npm install`, Start Command: `npm start`로 설정합니다. 무료 플랜을 선택할 수 있는 경우 테스트용으로 선택합니다.
4. 배포가 완료되면 Render에서 발급된 `https://...onrender.com` 주소를 카카오톡 단톡방에 공유합니다.
5. 서버가 잠들어 있다가 다시 켜지는 무료 플랜에서는 첫 접속이 지연될 수 있습니다. Render 요금/무료 플랜 제공 여부는 변경될 수 있습니다.

## 주의사항
- 모든 접속자는 동일한 하나의 방에 들어갑니다. 서버 인스턴스가 여러 개면 참가자가 분산될 수 있으므로 단일 인스턴스로 운영하세요.
- 서버 재시작 시 참가자와 경기 결과는 초기화됩니다. 계정/DB는 없습니다.
- 경기 중 신규 참가자는 입장할 수 없고 다음 경기부터 입장할 수 있습니다.
- 경기 종료 시 누군가 다시하기를 누르면 전체 대기실로 돌아갑니다.
- 브라우저를 새로고침하거나 연결이 끊어지면 재입장해야 합니다.
- 소규모 친구 테스트용이며, 부정 클릭 방지/운영자 기능/지속 저장은 구현되지 않았습니다.
